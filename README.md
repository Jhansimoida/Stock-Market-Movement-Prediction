# Stock Market Movement Prediction Using Machine Learning

## Overview

This project predicts stock market movement (UP/DOWN) using a Random Forest Classification model trained on historical stock market data.

## Dataset

- Dataset: COALINDIA Historical Stock Data
- Format: CSV
- Size: 110 KB

## Features Used

- Price Change
- Daily Return
- High-Low Difference
- Volatility
- Volume Change
- Moving Average (MA20)

## Machine Learning Pipeline

1. Data Collection
2. Data Preprocessing
3. Feature Engineering
4. Train-Test Split
5. Random Forest Model Training
6. Prediction
7. Performance Evaluation
